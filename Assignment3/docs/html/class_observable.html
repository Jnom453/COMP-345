Detailed Description

Base class for objects that notify observers of changes.

Map, Tower, Critter and CritterGroup inherit from this class. It keeps a list of Observer pointers and calls Observer::update() on each of them when the derived class calls notifyObservers().

The Observable does not own its observers. It stores raw pointers, so an observer must outlive the subject or be detached before it is destroyed.

void Observable::notifyObservers ( )
inlineprotected

Calls update() on every registered observer.

Derived classes call this after each change to their state. It loops over a copy of the observer list, so an observer can safely detach itself while it is being notified.
