Detailed Description

Window that displays one critter and redraws it when it changes.

Shows the critter's level, hit points, strength, speed, reward, position and whether it is alive. The observer is attached to the critter with Critter::attach(); the critter notifies it when it takes damage, is slowed, moves or reaches the exit.
