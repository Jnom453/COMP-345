Detailed Description

Console test cases for the three design patterns of Assignment 3.

Run it with ./a3_tests. Each CHECK prints PASS or FAIL; the program returns 0 only if every check passed. The tests are grouped by pattern: Strategy (targeting), Factory (critters and waves), Decorator (towers) and a few tests of the Game that uses them together.
