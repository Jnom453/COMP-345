Detailed Description

Raises the wrapped tower by one level.

Game rules (the same as Tower::upgrade()): each level adds 5 power and 1.0 range. The price of the next level is the buying cost times the current level, and the price that was paid is partly returned when the tower is sold: the refund value goes up by half of the price of this upgrade.

The decorator does not take the coins itself. Game::upgradeTower() asks the tower for getUpgradeCost(), takes the coins from the player and then wraps the tower in a LevelUpDecorator.
