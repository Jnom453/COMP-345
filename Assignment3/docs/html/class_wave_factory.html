Detailed Description

Creates each wave of critters using the critter factories.

The WaveFactory owns one factory per kind of critter and decides, for each place in the wave, which factory to ask. The choice depends on the number of waves already destroyed, so the further the player gets, the more kinds of critters appear and the harder the next wave is.

Game rule: waves get harder as more waves are destroyed. For the next wave number n = (waves destroyed) + 1:

  • the wave has 3 + n critters;
  • from wave 3, every third critter is a Fast critter;
  • from wave 5, every fourth critter is a Tank critter;
  • from wave 8, the last critter of the wave is a Boss;
  • all other critters are Normal. (A place that qualifies for several kinds takes the first one in the order Boss, Tank, Fast.)
