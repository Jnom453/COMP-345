Detailed Description

Holds the player's coins, the currency of the game.

Game rules:

  • Coins are spent to buy and upgrade towers.
  • Coins are earned by killing critters.
  • Coins are stolen by critters that reach the exit.
  • The player cannot spend coins he does not have, and the balance never goes below 0.
