Detailed Description

Abstract factory that creates critters of one kind for a given wave.

This is the Factory (Factory Method) design pattern. Code that needs a critter (the WaveFactory) only knows this interface and asks it to createCritter(); each concrete factory decides the kind and the statistics of the critter it builds. A new kind of critter is added by writing a new factory, without changing the code that uses the factories.

The statistics grow with the wave number, so a later wave is harder.
