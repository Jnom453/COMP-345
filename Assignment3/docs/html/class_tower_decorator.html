Detailed Description

A Tower that wraps another Tower and forwards everything to it.

This is the Decorator design pattern. A decorator is itself a Tower, so the game and the other decorators can use it exactly like a plain tower. It owns the tower it wraps ("component") and by default passes every call on to it. The concrete decorators (LevelUpDecorator, SplashDecorator, BurningDecorator, FreezingDecorator) override only the few functions they change, so decorators can be stacked in any order, for example Burning(Splash(LevelUp(DirectDamageTower))).

Game rule: upgrading a tower during play changes its behavior; this is done by wrapping the tower in a new decorator instead of editing the tower.
