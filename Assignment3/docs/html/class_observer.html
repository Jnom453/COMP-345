Detailed Description

Interface for objects that want to be told when an Observable changes.

Every view in the project (MapObserver, TowerObserver, CritterObserver, CritterGroupObserver) implements this interface. An observer registers itself with an Observable through Observable::attach(). From then on the Observable calls update() each time its state changes.

Called by the observed object whenever its state changes.
