Detailed Description

Strategy interface: chooses one target among the critters in range.

This is the Strategy design pattern. A Tower holds a pointer to a TargetingStrategy and asks it which critter to shoot. Because the tower only knows this interface, the strategy can be replaced while the game is running (Tower::setStrategy()) without changing the tower or the game loop.

Game rule: when several critters are in range, the tower must pick exactly one of them as its target.
