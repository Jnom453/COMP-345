Detailed Description

Builds a wave of critters that gets harder with the wave number.

Game rule: each wave is stronger than the one before it. For wave n:

  • number of critters: 3 + n
  • level: n
  • hit points: 50 + 15n
  • strength: 5 + n
  • speed: 1.0 + 0.1n
  • reward: 10n coins
