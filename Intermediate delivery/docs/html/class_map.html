Detailed Description

A rectangular grid of cells with an entry point and an exit point.

Game rules:

  • Every cell is scenery (towers go here) or path (critters walk here).
  • A map has exactly one entry and exactly one exit. Both must be path cells.
  • A map is valid only if the entry is connected to the exit by a chain of path cells (moving up, down, left or right).

Map is an Observable: every change to a cell, the entry or the exit notifies the attached observers (see MapObserver).

Cells are addressed by (row, column), with row 0 at the top and column 0 on the left.
