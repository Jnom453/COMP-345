Detailed Description

Window that displays a tower's characteristics and redraws them when the tower changes.

Shows the tower's name, level, power, range and rate of fire. The observer is attached to the tower with Tower::attach(); the tower notifies it after each upgrade.

The observer reads the tower's current values each time it redraws, so update() does not need to carry any data.
