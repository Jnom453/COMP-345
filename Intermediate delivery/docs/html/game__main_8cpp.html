Detailed Description

The SFML window of the playable game.

Draws the Game (map, towers, critters, coins, lives) and turns mouse clicks and key presses into calls on Game. All the rules live in Game.cpp.

Controls:

  • 1, 2, 3: choose the tower type to build (direct, area, slow)
  • left click on a green cell: buy and place the chosen tower
  • left click on a tower: select it
  • U: upgrade the selected tower, S: sell it
  • SPACE: start the next wave
  • R: restart, ESC: quit
